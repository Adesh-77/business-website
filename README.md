# Business Website

This is a simple business website to showcase products and let customers order using Google Forms.

## Features
- Company branding
- Product showcase with images
- Google Form integration for orders
- Mobile-friendly design

## How to Use
1. Replace `YOUR_GOOGLE_FORM_LINK` in `index.html` with your actual Google Form link.
2. Add product images inside the `images/` folder.
3. Host on **GitHub Pages**:
   - Push this repo to GitHub
   - Go to repo → Settings → Pages → Select `main` branch → Save
   - Your site will be live at: `https://your-username.github.io/business-website/`
